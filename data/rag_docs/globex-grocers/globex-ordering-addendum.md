# Globex Grocers Ordering Addendum

## Approval threshold
For Globex Grocers the approval threshold is **USD 5,000** per order. Orders above this value require an
approver.

## Payment limit
The Globex per-order payment limit is **USD 25,000**.

## Organic sourcing
Globex requires certified-organic suppliers for all dairy SKUs.
